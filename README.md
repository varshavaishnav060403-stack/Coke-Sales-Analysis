# Coca-Cola Sales Analysis using Excel

## Project Overview

This project analyzes Coca-Cola sales data across major American retailers using Microsoft Excel. The objective is to identify sales trends, regional performance, retailer efficiency, and profitability patterns to support data-driven business decisions.

## Business Problem

How can Coca-Cola optimize sales and profitability across different retailers, brands, and regions?

## Dataset

The dataset contains transactional sales records including:

- Retailer
- Invoice Date
- Region
- State
- City
- Beverage Brand
- Price per Unit
- Units Sold
- Total Sales
- Operating Profit
- Operating Margin

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

## Analysis Performed

### Data Cleaning
- Standardized column names
- Verified data types
- Checked for missing values
- Organized data for analysis

### Sales Analysis
- Total sales by retailer
- Brand-wise sales performance
- Regional sales comparison

### Profitability Analysis
- Operating profit analysis
- Operating margin comparison
- High and low-performing markets

### Time Series Analysis
- Monthly sales trends
- Seasonal demand patterns
- Revenue growth tracking

## Key Insights

- West region generated the highest sales revenue.
- Coca-Cola was the top-performing beverage brand.
- Sodapop was the leading retailer by sales.
- Sales peaked during the second half of the year.
- Strong operating margins were observed in high-performing regions.

## Business Recommendations

1. Increase focus on high-performing regions.
2. Strengthen partnerships with top retailers.
3. Promote best-selling beverage brands.
4. Prepare inventory for peak-demand months.
5. Monitor profitability alongside sales growth.
